# Projet : Dark_to_Light

## Description
Ce projet est un simple commutateur permettant de basculer entre le **mode sombre (Dark mode)** et le **mode clair (Light mode)** en utilisant **HTML, CSS et JavaScript**.  
L'état du thème est enregistré dans `localStorage` pour être conservé lors du rechargement de la page.

---

## Structure des fichiers

- **index.html** : Contient la structure de la page avec un bouton de basculement.
- **style.css** : Définit les styles des thèmes (clair et sombre) ainsi que l'apparence du bouton.
- **script.js** : Gère le changement de thème et enregistre la préférence de l'utilisateur.

---

## Fonctionnalités

✔ Basculement entre le mode clair et le mode sombre via un bouton.  
✔ Sauvegarde automatique du thème préféré grâce au `localStorage`.  
✔ Effet visuel avec un **curseur animé** et des icônes 🌜/🌞 pour représenter le mode.  
✔ Transition fluide des couleurs pour une meilleure expérience utilisateur.

---

## Comment utiliser ?

1. **Ouvrir le fichier `index.html`** dans un navigateur.  
2. **Cliquer sur le bouton** pour changer le thème.  
3. **Actualiser la page** pour voir que le thème choisi est sauvegardé.

---

## Améliorations possibles

- Ajouter une **transition plus fluide** entre les couleurs.
- Modifier aussi la couleur du **texte** en fonction du thème.
- Ajouter plus de **personnalisation** (choix de couleurs, animations, etc.).
- Corriger un petit bug dans `script.js` : remplacer `themeToggleToggle.checked = true;` par `themeToggle.checked = true;`.

---

## Technologies utilisées

🖥 **HTML** - Structure de la page  
🎨 **CSS** - Styles et animations  
⚡ **JavaScript** - Gestion du changement de thème et sauvegarde dans `localStorage`
